## 🔭 Featured projects

- **[fusion-dedicated](https://github.com/AndreikaKopeika/fusion-dedicated)** — headless dedicated server for BONELAB Fusion. No game, no VR headset, no host player: it runs on any spare Linux box, shows up in the in-game server browser and ships with a web control panel. `C#` `.NET 9`
- **[ZenSense](https://github.com/AndreikaKopeika/ZenSense)** — DualSense haptics over Bluetooth on Linux. A pure-Bash TUI that routes game audio to the controller's haptic motors, with a built-in profile builder. `Bash` `PipeWire`
- **[OpenUI](https://github.com/AndreikaKopeika/OpenUI)** — GUI library for OpenComputers: windows, widgets, dialogs, canvas drawing and 3D scenes — on a computer inside the game. `Lua`
